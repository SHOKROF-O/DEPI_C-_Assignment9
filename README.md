# Session 09 - Assignment

C# - ASP.Net Course

Topics: Primary Constructors, Records, Singleton, var & dynamic, Anonymous Types, Extension Methods, Unit Testing (xUnit).

## Console Project

- Patient.cs - Patient class (primary constructor) and PatientDto record.
- PatientMapper.cs - maps Patient to PatientDto.
- AppLogger.cs - Singleton pattern.
- TextHelper.cs - extension methods on string.
- FineCalculator.cs - Add, Subtract, Multiply, Divide.
- Program.cs - runs everything with explanatory comments.

## Test Project

- FineCalculatorTests.cs - 6 xUnit tests (AAA pattern).

## Notes

Needs two projects: a console app and an xUnit test project.
